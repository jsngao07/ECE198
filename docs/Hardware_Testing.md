# Hardware Testing

## Components Tested
- Arduino UNO R4 Minima
- OLED Display (128×64)
- Potentiometer
- Push Buttons (D3–D6)

## Test Results
- **OLED Display:** Passed
- **Potentiometer:** Passed
- **Push Buttons:** Passed

## Issues Encountered
During testing, the potentiometer and buttons weren't working properly at first. After checking the wiring, I found that some holes on the breadboard weren't making good connections.

Solution: Move the wires to different holes and tested everything again. After that, both the potentiometer and buttons worked as expected.

## Conclusion
All hardware components are now working properly, and we're ready to move on to software integration.
